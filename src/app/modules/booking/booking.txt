1. POST /booking → returns { paymentUrl }
2. Frontend redirects user to paymentUrl (Stripe checkout or PayPal approve page)
3. User completes payment → redirected back to:
   - Stripe: /payment/success?bookingId=X&session_id=Y
   - PayPal: /payment/success?bookingId=X&token=Y (token = orderId)
4. Frontend calls:
   - GET /payment/verify-stripe?sessionId=Y
   - POST /payment/verify-paypal { orderId: Y }
5. Backend confirms booking status → CONFIRMED
